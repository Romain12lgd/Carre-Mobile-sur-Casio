# Moving Square on Casio Calculator

A lightweight Python mini-project built for Casio graphic calculators using the `casioplot` library. This program allows users to smoothly move a square across the calculator screen using the directional pad.

## 🎯 Objective
The goal of this program is to freely pilot and navigate a square shape across the screen while exploring real-time graphic coordinates and smooth rendering on hardware constraints.

## 🕹️ Controls
- **Arrow Keys (Up, Down, Left, Right)**: Move the square across the screen.

## 🚀 Features
- Smooth, real-time geometric shape movement.
- Boundary collision detection to keep the shape inside the screen limits.
- Optimized rendering to ensure a lag-free experience.

## 🛠️ Prerequisites
- A Python-compatible Casio graph math+  graphic calculator (or a compatible emulator supporting `casioplot`).

## 💻 Installation & Usage
1. Transfer the Python script to your calculator using Casio's connectivity software.
2. Open the Python application on your calculator.
3. Run the script to start the animation.
